Privacy Policy

Desktop Calendar · last updated November 23, 2026

Desktop Calendar is a personal desktop widget used only by its developer, on their own laptop. It is not a public service.

What data it accesses

With my permission through Google sign-in, the app accesses only:

  • my own Google Calendar events (to show, create, edit and delete them), and
  • my own Google Tasks (to show them and mark them done).

It does not access any other Google data.

How the data is used and stored

  • Calendar events and tasks are displayed locally on my laptop, in a desktop widget.
  • A local cache of event and task details is kept on the laptop so the widget can work offline.
  • Google sign-in tokens are stored only in the laptop's local keyring (KDE Wallet).

Sharing

The app talks only to Google's own APIs. Nothing is sent to any other server. No data is shared, sold, or used for advertising or analytics.

Revoking access

Access can be removed at any time at myaccount.google.com/connections. Deleting the local cache and keyring entry removes all locally stored data.

Google API Services User Data Policy

Desktop Calendar's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
